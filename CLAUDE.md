# CLAUDE.md

## Проверка после исправлений

После любых исправлений обязательно:

1. **Запустить e2e-тесты:**
   ```
   cd tests/e2e && npm install && npx playwright test
   ```
   Все тесты должны пройти (`passed`).

2. **Проверить диагностику** (LuCI → Podkop Xray → Diagnostics → Run Diagnostic,
   либо `podkop-xray check_proxy` на роутере).
   Система должна увидеть **два разных IP**: `proxy_ip` (через VPN) ≠
   `direct_ip` (прямой выход) — поле `ip_different: true`. Совпадение IP
   означает, что трафик не идёт через прокси.

Тестовый роутер: `192.168.90.5` (root). Параметры e2e — через env
`ROUTER_URL` / `LUCI_USER` / `LUCI_PASS`.

## Особенности тестового роутера после сброса к заводским

Топология стенда: кабель аплинка воткнут в **LAN-порт** (роутер в одном
сегменте `192.168.90.0/24` с интернет-роутером `192.168.90.1`), WAN-порт без
линка. После factory reset нужно вручную восстановить:

1. **Интернет роутеру** — нет default route на аплинк:
   ```
   uci set network.lan.gateway='192.168.90.1'
   uci set network.lan.dns='192.168.90.1'
   uci commit network && /etc/init.d/network reload
   ```
2. **Часы** — без интернета на старте NTP не синхронизируется, неверная дата
   ломает проверку TLS-сертификатов (`SSL verify error`). Лечится после п.1
   (ntpd синхронизируется) либо вручную: `date -s "YYYY-MM-DD HH:MM:SS"`.
3. **SSH host key** меняется — на рабочей машине: `ssh-keygen -R 192.168.90.5`.
4. `install.sh` ставит **released**-версию с GitHub — без правок из репозитория.
   Чтобы развернуть исправленный код, после установки залить `files/` и
   `luci-app-podkop-xray/` поверх.

Эти ручные шаги предполагается убрать, запекув настройки сети в кастомную
прошивку (uci-defaults) — тогда п.1–2 не понадобятся.
